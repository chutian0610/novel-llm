# Novel LLM

Local, single-author workbench for planning, drafting, reviewing, and exporting long-form fiction. See [GLOSSARY.md](GLOSSARY.md) and [docs/architecture.md](docs/architecture.md).

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (chutian0610/novel-llm) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the repo root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
