# Use PostgreSQL full-text search with zhparser

Retrieval uses PostgreSQL text search with a custom PostgreSQL 16 image that includes both zhparser and pgvector. A project-defined Chinese text-search configuration uses zhparser segmentation with GIN indexes and `websearch_to_tsquery`, while structured entity and alias recall handles proper nouns that generic segmentation may miss. Retrieval is project-scoped and combines configurable weights for structured entity and event hits, full-text rank, chapter recency, and narrative-state relevance; selected and excluded sources are recorded for explanation. This keeps first-version search inside PostgreSQL and avoids treating trigram similarity as Chinese full-text search; pgvector is installed for future use but is not part of the initial retrieval path.
