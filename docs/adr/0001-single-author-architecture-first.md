# Keep Novel LLM single-author and architecture-first

Novel LLM is a personal workbench for one author, not a multi-user or collaborative product. The first implementation establishes the complete job, workflow, worker, and review framework before deepening generation quality features, while deferring accounts, registration, authentication, sharing, and organizational permissions. Any future multi-user mode is a separate architecture decision and must revisit ownership, access control, credentials, quotas, and audit boundaries.
